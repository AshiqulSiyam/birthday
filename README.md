# 🌸 Lilium Orientalis // Project: Moonlight

> **An interactive 3D procedural botanical growth experience and birthday tribute for Nusrat Jahan Sadia (03 November).**

---

## ✨ Features

- **Procedural 3D Stargazer Lily Simulation (Three.js / WebGL)**:
  - Real-time botanical synthesis with procedural petal curvature, reflexing tips, undulating ruffled margins, and 240+ raised 3D crimson papillae speckles.
  - Realistic reproductive organs: 6 slender recurving stamens with heavy rust-orange pollen anthers and a central emerald pistil with a 3-lobed stigma.
- **4 Cinematic Growth Phases**:
  - `Stage 1`: Wireframe Matrix & Botanical Grid initialization.
  - `Stage 2`: Emergence of organic stem & foliage with wireframe holographic scanning.
  - `Stage 3`: Pigmentation & petal materialization (crimson-magenta heart and lime-green throat).
  - `Stage 4`: Full Stargazer bloom complete with celestial lunar halo and floating ambient pollen fireflies.
- **Synthesized Web Audio Polyphonic Music Box**:
  - Pure Web Audio API synthesized arrangement of *"Happy Birthday to You"* with resonant music-box chime envelopes and continuous looping.
- **Frosted-Glass Terminal Card**:
  - Interactive decrypted message with dual tabs (*Polished Compilation* & *Raw Heartfelt Note*).
  - High-visibility radiant **Campus Tour Request Box** with glowing golden-rose sunset gradient.
  - Interactive celebration button triggering 2D canvas confetti physics.

---

## 🛠️ Tech Stack

- **Graphics**: [Three.js](https://threejs.org/) (WebGL)
- **Audio**: Web Audio API (Synthesized frequency oscillators & exponential gain envelopes)
- **Styling**: Modern CSS3 (Glassmorphism, CSS Custom Properties, 3D perspective transforms)
- **Language**: Vanilla JavaScript (Zero external runtime dependencies)
